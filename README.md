# ColorSwitcher - QTimer, лямбда-слоты и динамические соединения

Учебный проект по дисциплине «Программирование на C++/Qt». Лабораторная работа №3.

## Возможности
*   **QTimer**: управление периодическими событиями (старт, стоп, изменение скорости).
*   **Режимы работы**: Цикл (переключение цветов по порядку), Случайный цвет, Мигание.
*   **Обработка событий**: переопределен `mousePressEvent` для холста (левый клик — следующий цвет, правый — предыдущий).
*   **Собственные сигналы**: событие клика мыши транслируется в сигнал `colorChanged`.
*   **Динамические соединения**: 
    *   Создание кнопок-цветов в рантайме с подключением к ним слотов.
    *   Разрыв соединений при очистке палитры.
    *   Переподключение обработчика сигнала `colorChanged` (смена строки статуса на заголовок окна).

## Сборка и запуск
1. Откройте `ColorSwitcher.pro` в Qt Creator.
2. Соберите проект (Ctrl+B) и запустите (Ctrl+R).

## Структура
*   `ColorWidget` — холст, отрисовывающий цвет и обрабатывающий клики мыши.
*   `PaletteButton` — кнопка, хранящая в себе объект `QColor`.
*   `MainWindow` — главное окно, управляющее таймером, интерфейсом и логикой соединений.
